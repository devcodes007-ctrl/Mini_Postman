
# Mini Postman

A lightweight API testing tool built using Python and Django.

## Technology Stack

- Python
- Django
- HTML5 and CSS3
- Bootstrap 5
- JavaScript
- Requests
- SQLite

## Planned Features

- Send GET, POST, PUT and DELETE requests
- Configure request headers and JSON bodies
- Inspect response status, headers and duration
- Display formatted JSON responses
- Save reusable API requests
- View request history
- Handle request errors safely

## Setup Instructions

1. Create and activate a Python virtual environment.
2. Install dependencies from requirements.txt.
3. Run `python3 manage.py migrate`.
4. Start the server with `python3 manage.py runserver`.
5. Open http://127.0.0.1:8000/ in your browser.
